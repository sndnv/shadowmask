This client

Bundles hls.js under Apache-2.0, whose bundle inlines url-toolkit (Apache-2.0) and eventemitter3 (MIT). All three notices are at vendor/hls.js.LICENSE.txt.

Metadata and subtitles

Metadata and artwork are fetched from TMDB, and subtitles from OpenSubtitles, each through an API key the server's operator supplies.

This product uses TMDB and the TMDB APIs but is not endorsed, certified, or otherwise approved by TMDB.

Ratings and certifications are supplemented by OMDb, whose data is licensed under CC BY-NC 4.0. OMDb is not endorsed by or affiliated with IMDb.com.

The server

The Rust crates linked into the server binary are credited in THIRD-PARTY-LICENSES.md. What the container image carries, including ffmpeg and the Debian packages, is described in SERVER-IMAGE-CREDITS.md.

Inside a running image those texts are at /usr/share/doc/shadowmask/, and every Debian package's copyright file is at /usr/share/doc/<package>/copyright.
